## KG-CRL

Code and Datasets for "KG-CRL: Knowledge-Enhanced Causal Representation Learning for Microbe-Disease Association Prediction"

#### Data

- data is a set of files for training and evaluating the performance of the proposed model.

#### Code

##### Requirement

The code has been tested running under Python 3.9.18. The required packages are as follows:

- numpy == 1.22.3
- pandas == 1.5.3
- torch == 2.0.1+cu118
- torch-geometric == 2.3.1
- scikit-learn == 1.2.2
- scipy == 1.10.1

##### Usage

```
git clone https://github.com/mengluli-web/KG-CRL
cd KG-CRL/code
python iters_cv_indep.py 
```
